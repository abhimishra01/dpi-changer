# Code review, maintainer lens: dpi-changer

Verdict: sound and small, and the byte logic is correct on all normal files (15/15 tests pass, 20,000 random-corruption runs and every truncation threw only the expected plain errors). 0 must-fix, 9 should-fix, 4 nice. Main risks: a corrupt PNG breaks "Download all", malformed EXIF can write outside its segment, and the legal pages print the build date as "Last updated".
